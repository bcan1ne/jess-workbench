How to make one, step by step
  1. Open this GitHub page ↗ (sign in if it asks).
  2. Token name — type anything, for example job board.
  3. Expiration — pick the longest option offered. When it runs out the board stops saving and you make a new one.
  4. Repository access — choose Only select repositories, then pick this repository.
    Do not leave it on "Public repositories" — that one is read-only and will not work.
  5. Permissions → Repository permissions. Find these two and set both to Read and write:
    • Actions
    • Contents
    Leave everything else alone. Metadata turns itself on — that is expected.
  6. Scroll down, press Generate token, and copy the long github_pat_… line straight away. GitHub only shows it once.
  7. Paste it in the box below and press Save token.

    The token stays in this browser and is never saved into the repository. If you ever think it has got out, delete it on GitHub and make a new one. See past searches ↗

    Set up another browser

    Credentials cannot be committed. A token in a public repository is revoked by GitHub within minutes, and until it is, it lets anyone rewrite the workflow that holds the Anthropic secret. This is the way round that.

    The link below contains your live credentials. Bookmark it; do not email it or paste it anywhere. Anyone who opens it arms their browser as if it were yours.

    Point the other phone's camera at this, then open the link it offers. Anyone who can see this screen can scan it, so close it when you are done.

    Open it once in each browser and the credentials save themselves. Kept as a bookmark, your browser's own bookmark sync carries it between devices — and the part after the # is never sent over the network, so the secret reaches no server and no log.
